# Posting Schedule

## Cadence
- 1 post per day
- Best times (Instagram algorithm data):
  - Weekdays: 7-9am or 6-9pm local audience time
  - Weekends: 9-11am

## Weekly Agent Pipeline
| Day | Task |
|-----|------|
| Monday | Agent runs find_content.md — finds 7 ideas for the week |
| Monday | Agent runs score_post.md — scores and filters |
| Monday | Agent runs write_caption.md — writes captions for approved ideas |
| Tuesday–Sunday | 1 post goes live per day from queue/ |

## Launch Day Exception
On day 1: publish 9 posts immediately to make the profile look established.
Use the best 9 scored ideas from the seed batch.

## Engagement Rule
Reply to every comment within the first 60 minutes of posting.
Use the AI agent to draft replies — keep tone warm and curious.
